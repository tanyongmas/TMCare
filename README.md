# TMCare - ระบบติดตามและดูแลผู้พิการและกลุ่มเปราะบาง
**เทศบาลตำบลตันหยงมัส อำเภอระแงะ จังหวัดนราธิวาส**

เว็บแอปพลิเคชันเพื่อการจัดการ ติดตาม เฝ้าระวัง และช่วยเหลือผู้พิการ ผู้ป่วยติดเตียง และกลุ่มเปราะบางในระดับท้องถิ่น ออกแบบให้ใช้งานง่ายบนสมาร์ทโฟนสำหรับ **คณะกรรมการชุมชน 7 ชุมชน**, **เจ้าหน้าที่กองสวัสดิการสังคม**, และ **ผู้บริหารเทศบาลตำบลตันหยงมัส**

---

## 🌟 จุดเด่นและฟังก์ชันหลักของระบบ

1. **การคัดกรองความเปราะบาง 3 ระดับสี (Triage Red / Yellow / Green)**:
   - 🔴 **สีแดง (วิกฤต/ติดเตียง)**: ADL 0-4 พึ่งพิงสมบูรณ์ ต้องใช้อุปกรณ์พยุงชีพ (เช่น เครื่องผลิตออกซิเจน, เตียงลม) ต้องได้รับการอพยพเป็นลำดับแรกเมื่อเกิดน้ำท่วม
   - 🟡 **สีเหลือง (ติดบ้าน)**: ADL 5-11 ต้องการความช่วยเหลือปานกลาง
   - 🟢 **สีเขียว (ติดสังคม)**: ADL 12-20 ช่วยเหลือตนเองได้
2. **การจำกัดสิทธิ์ข้อมูลตามชุมชน (Community Data Scoping)**:
   - คณะกรรมการชุมชนล็อกอินด้วย **การเลือกชุมชน + รหัส PIN 6 หลัก** จะเห็นและจัดการได้เฉพาะลูกบ้านในชุมชนของตนเองเท่านั้น
   - เจ้าหน้าที่กองสวัสดิการสังคมและผู้บริหารสามารถตรวจสอบภาพรวมได้ครบทั้ง 7 ชุมชน
3. **ระบบ 4 โมดูลหลัก**:
   - 📋 **การติดตามและเฝ้าระวัง (Monitoring)**: ทะเบียนประวัติ, แบบประเมิน ADL คำนวณสีอัตโนมัติ, บันทึกการเยี่ยมบ้านพร้อมภาพถ่ายและพิกัด GPS
   - 🎁 **สวัสดิการและการเงิน (Welfare)**: ผ้าอ้อมผู้ใหญ่ (สปสช.), รถเข็นวีลแชร์, ถุงยังชีพ, ระบบส่งคำร้องจากชุมชน และระบบอนุมัติของเจ้าหน้าที่
   - 🚑 **การแพทย์ฉุกเฉิน (EMS)**: บัตรข้อมูลการแพทย์ฉุกเฉิน (โรคประจำตัว, ยาที่แพ้, อุปกรณ์พยุงชีพ), ปุ่มโทรด่วน 1669, ปุ่มคัดลอกพิกัดนำทาง Google Maps ส่งต่อให้กู้ภัยใน LINE ได้ทันที
   - 🌊 **การจัดการภัยพิบัติ (Disaster Management)**: แผนที่ GIS (Leaflet + OpenStreetMap) ปักหมุดบ้านแยกสี 3 ระดับ, โหมดเช็คชื่อและสถานะการอพยพ Real-time
4. **สถาปัตยกรรมพร้อมขยาย (Supabase-Ready Adapter Pattern)**:
   - โหมดทดสอบจำลอง (Mock Data) ใช้งานได้ทันที
   - เชื่อมต่อ **Google Sheets + Google Apps Script (GAS)** สำหรับระยะเริ่มต้น ฟรี 100%
   - มีไฟล์ `schema.sql` พร้อมย้ายไปใช้ **Supabase (PostgreSQL + PostGIS)** ในอนาคตโดยไม่ต้องแก้ UI หน้าบ้าน

## 🚀 การติดตั้งและนำขึ้นใช้งาน (Deployment Guide)

### ขั้นตอนที่ 1: นำขึ้น GitHub Pages (Frontend)
1. นำโค้ดทั้งหมดในโฟลเดอร์นี้ขึ้น Git Repository บน GitHub
2. ไปที่ **Settings** ของ Repository -> เลือกเมนู **Pages** ด้านซ้าย
3. ในส่วน **Build and deployment**:
   - Source: เลือก `Deploy from a branch`
   - Branch: เลือก `main` (หรือ `master`) และโฟลเดอร์ `/ (root)`
   - กด **Save**
4. รอประมาณ 1-2 นาที จะได้ URL เช่น `https://<username>.github.io/<repo-name>/` พร้อมใช้งานทันที

---

### ขั้นตอนที่ 2: เชื่อมต่อ Google Sheets + Google Apps Script (Backend ระยะที่ 1)
1. เปิด [Google Drive](https://drive.google.com) แล้วสร้าง **Google Sheets** ใหม่ ตั้งชื่อว่า `TMCare_Database`
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมในหน้าต่างออก แล้วคัดลอกโค้ดจากไฟล์ `backend/gas/Code.gs` ทั้งหมดไปวาง
4. บันทึกโครงการ (กดรูปแผ่นดิสก์)
5. ในแถบเครื่องมือด้านบน เลือกฟังก์ชัน **`setupDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)**
   - ในครั้งแรก Google จะขออนุมัติสิทธิ์การเข้าถึง ให้กด *ตรวจสอบสิทธิ์ (Review permissions)* -> เลือกบัญชี Google -> *ขั้นสูง (Advanced)* -> *ไปที่... (ไม่ปลอดภัย)* -> *อนุญาต (Allow)*
   - เมื่อรันเสร็จ ใน Google Sheets จะมีชีตถูกสร้างขึ้นครบทั้ง 5 ตารางพร้อมข้อมูลเริ่มต้น
6. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** มุมบนขวา -> เลือก **การทำให้ใช้งานได้รายการใหม่ (New Deployment)**
   - คลิกไอคอนรูปฟันเฟือง -> เลือกประเภท **เว็บแอปพลิเคชัน (Web App)**
   - **คำอธิบาย**: TMCare Production v1
   - **ดำเนินการในฐานะ (Execute as)**: ตัวฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ GitHub Pages ยิง API เข้ามาได้)*
   - กด **ทำให้ใช้งานได้ (Deploy)**
7. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
8. เปิดหน้าเว็บ TMCare -> กดปุ่มสถานะฐานข้อมูลมุมบนขวา (หรือปุ่ม **MOCK**) -> เลือกโหมดเป็น **Google Apps Script** -> วาง URL ที่คัดลอกมา -> กด **บันทึกการตั้งค่า**

---

### ขั้นตอนที่ 3: การย้ายไปใช้ Supabase ในอนาคต (Backend ระยะที่ 2)
1. สร้างโปรเจคใหม่บน [Supabase](https://supabase.com)
2. ไปที่ **SQL Editor** ใน Supabase Dashboard
3. คัดลอกสคริปต์จากไฟล์ `backend/supabase/schema.sql` ไปวางแล้วกด **Run** เพื่อสร้างตารางและเปิดใช้งาน Row Level Security (RLS)
4. นำ `Project URL` และ `anon key` จาก Supabase Settings (API) ไปกรอกในหน้าตั้งค่าของ TMCare Web App แล้วเปลี่ยนโหมดเป็น **Supabase**

## 📁 โครงสร้างโปรเจค

```text
TMCare/
├── index.html                  # หน้าจอหลัก Single Page Application (Mobile-First)
├── manifest.json               # สำหรับติดตั้งเป็น Progressive Web App บนมือถือ
├── css/
│   └── styles.css              # Custom styling, Badge 3 สี, แผนที่ Leaflet
├── js/
│   ├── config.js               # การตั้งค่าระบบ และข้อมูลพิกัด 7 ชุมชน ทต.ตันหยงมัส
│   ├── app.js                  # Controller หลัก จัดการ UI, แผนที่ GIS, กราฟสถิติ
│   └── services/
│       ├── apiService.js       # Adapter กลาง ควบคุม Community Scoping และสลับ Driver
│       ├── gasDriver.js        # Driver สำหรับเชื่อมต่อ Google Apps Script & Google Sheets
│       └── supabaseDriver.js   # Driver สำหรับคุยกับ Supabase ในอนาคต
├── backend/
│   ├── gas/
│   │   └── Code.gs             # โค้ด Google Apps Script ครบวงจร
│   └── supabase/
│       └── schema.sql          # สคริปต์ PostgreSQL + PostGIS + RLS
└── README.md                   # คู่มือการใช้งานและติดตั้งระบบ
```
